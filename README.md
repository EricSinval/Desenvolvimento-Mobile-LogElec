## 📋 Descrição
LogElec é uma plataforma que conecta empresas geradoras de lixo eletrônico a coletoras especializadas, facilitando o agendamento de coletas e garantindo o descarte sustentável.

Simples, educativa e eficiente, ajuda negócios a gerir resíduos de forma responsável e a reforçar seu compromisso ambiental.
